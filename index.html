Sources de données

Paramètres généraux, enregistrés sur le serveur et communs à tous les visiteurs. À corriger uniquement si l'un de ces services externes change d'adresse.

Communication avec le serveur

Paramètres généraux, enregistrés sur le serveur et communs à tous les visiteurs. Le serveur d'enregistrement (relais) écrit dans le dépôt les modifications faites dans l'application. Enregistrer ici envoie aussi les adresses de l'onglet Sources.

Le code administrateur n'est jamais enregistré : il n'est gardé que le temps de cet onglet du navigateur, pour s'identifier auprès du relais.

Modifications des fonds de plan

Affiche la couche « Plans d'ensemble » et ouvre l'outil de placement des références de planche (clic dans le texte d'une étiquette).

Affiche la couche « Numéros interstation » et ouvre l'outil de placement des numéros d'interstation : on glisse le texte où l'on veut, puis on choisit le tronçon auquel il se raccroche (survol d'un tunnel = son axe s'allume).

À venir : remplacer les données Metro_export_SHP depuis l'application (nécessite l'enregistrement sur le serveur). Le chargement prendra un ou plusieurs fichiers du dossier du shapefile (.shp, .dbf, .shx, .prj, .cpg…), pas seulement le .shp.
